3D MathGrid

Instructions

Building the structure

Drag the sliders to build. Scale: Units → Tens → Hundreds → Thousands → 10K → 100K → Million.

Add & Subtract

Set A and B on the sliders, then use the + / − buttons to watch the two piles interact, one click per place value, starting with the units. The Quiz button asks you to guess the answer before each demo proves it. Reset clears A and B back to 0.

Color Saturation

0 = grayscale, 100 = normal, 200 = vivid.
